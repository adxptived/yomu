# Соответствие чек-листу ридера

Ветка: `feature/reader-parity`. Дата: 2026-11-11.
Проверка: чтение исходников; сборка `:app:assembleDebug` — см. итог в конце.

Обозначения: ✅ есть и работает, 🟡 есть частично, ❌ отсутствует.

## 1. Масштаб и работа со страницей (PDF, DJVU, сканы, комиксы)

| Пункт | Статус | Где / что сделано |
|---|---|---|
| Приближение щипком и двойным тапом | ✅/🟡 | Комиксы и постраничный PDF — telephoto (`MangaReaderView`, `PdfReaderView`); прокрутка PDF — щипок, двойного тапа нет; текст EPUB — масштаб шрифтом, не жестом |
| Фиксация масштаба кнопкой сбоку | ✅ | Новое: `zoomLock` в `PdfSettings`/`MangaSettings`, кнопка-замок на правом краю ридера (`ReaderScreen`), общий `lockedZoom` в контроллерах. Следующая страница открывается в том же увеличении |
| Обрезка полей: авто и ручная | ✅ | PDF: `PdfSource.detectMargins` + `PdfController.crop`; ручная — теперь **четыре отдельных ползунка** (слева/справа/сверху/снизу) вместо одного общего. Комиксы: `cropBorders` |
| Reflow текста из PDF | ✅ | `PdfSettings.reflow`, `PdfReflow`/`PdfReflowText` |
| Reflow текста из DJVU | ❌ | Формат DJVU не поддерживается: нет парсера и рендера. Файлы `.djvu` не открываются. Нужен отдельный нативный движок (DjVuLibre) — вне рамок этого прохода |
| Двухстраничный режим в горизонтали | ✅ | PDF `PdfMode.DUAL`, комиксы `dualPageLandscape`; **новое:** текст в две колонки (`TextReaderSettings.dualPageLandscape`, шаг листания на разворот в `reader.js`) |
| Инверсия и контраст для сканов/PDF | ✅ | PDF: ночной режим (инверсия) + новые ползунок контраста и «оттенки серого». Комиксы: яркость, контраст, серость, инверсия |
| Блокировка ориентации и поворот | ✅ | `ReaderOrientation` + `ReaderWindowEffects` |

## 7. Изменения в этом проходе

- `PdfSettings`: `contrast`, `grayscale`, `zoomLock`; `MangaSettings`: `zoomLock`.
- `PdfController`/`MangaController`: `lockedZoom`; в представлениях — сохранение и восстановление масштаба.
- `ReaderScreen`: кнопка-замок масштаба у правого края.
- `ReaderSettingsSheet`: 4 ползунка ручной обрезки, контраст, серость, фиксация масштаба.
- `ReaderViewModel`: стек переходов (до 50), мгновенное применение скорости/тона TTS, выбор внешнего словаря.
- `SelectionAction.DICTIONARY` + `DictionaryApp` + `DictionaryLauncher` + настройка приложения.
- `ReadingStatus`: +3 статуса; `Book.favorite`, `books.favorite`, миграция БД 8→9.
- `LibraryFilter.favoritesOnly`; звезда в карточке книги, массовая кнопка, фильтр и чип.
- Поиск библиотеки: описание и теги.
- `chapter_progress` + миграция 9→10: позиция каждой главы, восстановление из TOC/«назад», сохранение в бэкап.
- Сохранение фильтров/типов библиотеки в DataStore.
- Сетка миниатюр PDF/комиксов (`ReaderPagesSheet`), рендер PDF-миниатюр через pdfium.
- «Осталось времени» в нижней строке текстового ридера.
- Автоночная тема по расписанию (`AutoNightMode`, часы «с/до», минутный тик в VM).
- Двухстраничный текст в горизонтали: `dualPageLandscape`, `EpubController.updateColumns`, шаг листания на разворот (`pageStep` в `reader.js`).
- `ReaderTtsService`: foreground-сервис `mediaPlayback`, platform MediaSession, уведомление с play/pause/stop; мост `TtsBus` между VM и сервисом.
- Синхронизация `chapter_progress`: поле `SyncBook.chapterProgress` (новейшая позиция на главу), валидация синк-файла, очистка при удалении книги, добавление в локальную ревизию.
- Тесты: `SyncMergerTest.chapterPositionsMergeNewestPerChapter`, миграция 9→10.
- Строки en/ru для всех новых элементов.

## 8. Осознанно не сделано (ограничения)

1. **DJVU** — нет движка; нужен DjVuLibre/нативная интеграция.
2. **Действия на произвольные зоны касания** — сейчас только предустановленные раскладки.
3. **Кэш страниц PDF** — фильтры контраста/серости применяются при отрисовке и не входят в ключ кэша (это дешевле, чем перерендер).
4. **TTS после смерти процесса** — сервис держит процесс живым при выключенном экране, но после принудительной остановки приложения чтение не возобновляется само.
