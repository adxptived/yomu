# Yomu user guide

Yomu is a reader for books, PDFs, comics and manga with a dictionary, translation and word repetition, a built-in editor and an online-source catalog.

## First launch

1. **Welcome** — a short feature list.
2. **Where are your books?** — pick one or more folders: Yomu adds the books and watches for new files (interval: Settings → Library). You can skip this step and import files manually.
3. **Translate into** — the language words and sentences are translated into.
4. The notification permission is needed for downloads, chapter updates and repetition reminders.

## Library

- **Import**: the "Import" button (files or a folder), "Open with Yomu"/"Share" from other apps. The "On import" mode: *copy* into app storage or *link* to the file (saves space, but the file must stay in place).
- **Formats**: EPUB, PDF, FB2/FB2.ZIP, MOBI/AZW3, DOCX, TXT, HTML, CBZ/ZIP, CBR/RAR, CB7/7Z, an image folder.
- **Tabs** (a pill row on top): "All", "Online (N)" and your own tabs. "+" makes a new one; one tab can hold both books and online titles. Long-press a tab: "Rename", "Move left/right", "Delete" (books and titles stay in the library). Put things into a tab: select books with a long press → "To tabs"; long-press an online title → "Tabs…"; on a title page — "⋮ → Tabs…".
- **Filter and view**: the "Filter" button (the number = active filters) opens a panel: type (books, PDF, comics, online), status (new, reading, finished), tags, languages, sorting (title, author, added, last read, progress), view (grid/list) and column count. Enabled filters show as chips below the buttons — a cross removes one, "Reset all" removes all. Next to them — a sort button and the grid/list switch; search by title/author/series — the magnifier button in the header.
- **Continue reading** — at the top of the "All" tab: the last book or online title with unread chapters as a large card, plus a row of the next ones.
- **The "Continue reading" widget** (since 2.0.0) — add it to the home screen from the widget list: the books and online titles you are reading, with cover and progress; tapping opens the book at the stop position, a title at the next chapter.
- **Online** — titles added with the heart in the catalog live in the library too: an "Online (N)" tab next to "All" (the same grid, sorting and filters as "Catalog → Library"; library search covers them) and an "From the catalog" shelf in "All". If there are no on-device books but online titles exist, a "No on-device books yet" card with an "Import" button replaces the empty screen.
- **Long press** — multi-select books: to tabs, mark finished, delete (with or without files), **"Edit metadata"** (the pencil icon on top, since 2.0.0) — authors, series with numbering (by name or in selection order), language, publisher, status and tags for all selected books at once; untouched fields stay per-book. An online title gets a menu: open, tabs, remove from the library.
- **The book card** (the "ⓘ" button in list view; in the grid — long-press a book and tap "ⓘ" on top): metadata, cover, series, tabs, status, "Read", "Edit", "Notes", book translation.
- **The long-press wheel**: hold a book and a ring of actions opens under the finger (read, details, rate, favourite, status, select, delete) with "cancel" in the middle. Drag to an action and lift the finger to run it; hold without dragging and the ring stays open, so an action can simply be tapped. Prefer tapping only? Settings → Long-press menus → "Choose by dragging in the wheel" (off: one tap per action).

## Reading

- **Tap zones**: the left/right part — page back/forward, the center — the menu. Volume keys turn pages too (enabled in reader settings).
- **The reading menu**: table of contents, in-book search, bookmark, settings, read-aloud (TTS with sentence highlighting and a sleep timer), reading statistics.
- **Where you are**: at the bottom of the menu — "Page N of ≈M" (for reflowable books the count depends on font and screen, hence "≈"), how long is left to the end of the chapter and book. Tapping the page number — "Go to page" (a number or percent). While dragging the slider you see where you will land (chapter and page); after a slider jump, a table-of-contents or search jump a "Back to page N" button appears. When the menu is hidden, a status line at the bottom: chapter, page, progress, clock and battery (configurable).
- **Reader settings** (the "Tt" button in the bottom menu): font size and theme always on top; below — "Text" (font, line/letter/word spacing, margins, alignment, hyphenation), "Screen" (themes, a custom theme — background and text color, brightness, the status line) and "Controls" (tap zones, volume, gestures). **Presets**: "Classic", "Large font", "Compact", "Spacious", "Easy reading" and your own ("Save current…"). A "For this book only" switch stores the settings separately for the opened book.
- **Word documents (DOCX)**: by default the text reflows to the screen like EPUB — with "Page by page", "Scroll chapter" or "Long strip" as the reading mode, like any other book. "⋮ → Page layout" (or the same on the book card) shows the document as A4 pages as printed — margins, headers and footers, footnotes, tables, images, numbering; the "Text mode" button on that screen returns to the reflowable reader. Two-finger zoom, the page number at the bottom, "Go to page" on top; the position is remembered. On first DOCX open the reader offers this mode itself. If the reading mode is "Scroll chapter" or "Long strip", a Word document opens in the reflowable reader even when "Word documents as printed pages" is switched on.
- **Manga**: left-to-right (default), right-to-left, vertical, webtoon (a feed) — pictogram tiles in "Tt → Manga"; fit width/height/screen; double-tap zoom; dual pages; page background (black/gray/white), page-turn animation, page number, preloading, margin crop; for webtoon — side margins and gaps. Image filters: brightness, contrast, grayscale, invert ("Reset image settings" restores defaults).
- **Manga tap zones** ("Tt → Controls"): layouts with diagrams, "Swap the zones", "Show zones on open" and a "Show zones now" button — the hint overlays the page for 3 seconds (automatically on the first title open and after changing zones or direction). Volume keys turn manga pages ("Volume up — forward" swaps them). In "right-to-left" the page slider also runs right-to-left.
- **PDF**: a page, scrolling or dual pages; zoom, text search and selection, a password for protected files, night inversion, margin crop, simplified text reflow. For scans without a text layer "Translate page" runs OCR first. Highlights (since 2.0.0) are saved into the PDF itself as standard annotations — other PDF apps show them; the file is appended, original bytes untouched. Toggle in Settings → Manga and PDF → Save highlights in PDF files; linked files are changed only if Yomu has write access.
- **Long-press menus** (since 2.0.0): a long press on a manga or comics page — a radial menu or a list of actions (translate, save the page, share, copy text, bookmark, set as cover, note). The menu style, actions and order — Settings → Long-press menus; the text-selection menu style (panel, radial, list) is there too.

## Audiobooks

- **Your own audiobooks**: add MP3, M4A/M4B, AAC, OGG/Opus, FLAC or WAV files like any book (Library → + → Files, "Open with" or "Share" from another app). "Folder as one book" turns a folder of tracks into one audiobook with the tracks as chapters; scan folders do the same for every sub-folder with two or more audio files. A ZIP of audio files (LibriVox, Internet Archive) is unpacked into the library. Titles, authors and covers come from the tags (the album tag for folders) or a `cover.jpg`/`folder.jpg` next to the tracks.
- **Catalog**: the built-in **LibriVox** source (public-domain audiobooks) offers "Listen online" — the book joins the library and streams chapter by chapter — and "MP3 (ZIP)" to download it for offline listening. The built-in **YouTube** source searches long videos (audiobooks, lectures), all videos or playlists; "Listen online" adds the video or the whole playlist. OPDS catalogs that link audio files download the same way; extension sources can offer a stream with the `application/rss+xml` or `application/x-yomu-audio-stream` link types.
- **By link** (Library → + → Audiobook by link, or "Share → Listen in Yomu" from YouTube, a podcast app or a browser): a **YouTube** video (its chapters — written or automatic — or description timestamps become chapters; dubbed videos play in the original voice), playlist (each video is a chapter) or channel (its uploads, oldest first); type words instead of a link to search YouTube and pick a video or playlist from the results; a **podcast** RSS/Atom feed (episodes in listening order), a direct audio file, or a web page that links one of those. Online books are streamed until you download them (below).
- **Offline listening**: online audiobooks (YouTube, podcasts, catalog streams) show a download button in the player. It saves every track on the device in the background (with a notification; "Only over Wi-Fi" from the download settings applies), resumes where it stopped, and the player then uses the saved files. "Delete downloaded files" streams the book again; deleting the book deletes them too.
- **NotebookLM**: NotebookLM pages need a Google sign-in, so Yomu cannot open links to them. In NotebookLM open the Audio Overview, choose ⋮ → Download (or Share) and open or share the file with Yomu — it becomes an audiobook like any audio file.
- **The player**: play/pause, back 10 s / forward 30 s, previous/next chapter, the chapter list (including chapters embedded in M4B and MP3 files), speed 0.5×–3× in steps of 0.05 and "Skip silence" (both kept per book), the time left in the book, a sleep timer (minutes, fading out over the last 20 seconds, or "end of chapter"). After a pause of more than a minute playback resumes a few seconds earlier (3–30 s, longer for longer pauses). The notification offers back 10 s / forward 30 s. Playback continues in the background with a notification, lock-screen, headset and Bluetooth controls; a bar at the top of the app shows the playing book. The position is saved every few seconds and on pause; listening time counts in the reading statistics. Library → filter → Type → Audiobooks shows only them.

## Profile: history, statistics, tracking, downloads

The Profile tab — reading time, streaks and achievements ("Overview"), plus the "Statistics", "History", "Tracking" and "Downloads" tabs (since 2.0.1). If the tabs do not fit, the row scrolls.

- **History** — a profile tab: what and when you read, by day, with reading time; books and online chapters together. Search, "Continue reading" (▶), "⋮ → Remove from history", clearing all history. On top — the daily-goal progress and the streak.
- **Statistics** — a profile tab or "⋮ → Reading statistics" in the reader: week, month, year or all time; comparison with the previous period, a per-day chart with the goal line, average per day, sessions, reading speed, best day, streaks, finished books, the most-read works, a heatmap, breakdown by hours and weekdays. The flag on top is the daily goal in minutes; "⋮ → Reset statistics" deletes sessions but not reading positions.
- Time is counted automatically while a book is open; a session ends after 5 minutes without actions.
- **Tracking** (since 2.0.1) — every title linked to MyAnimeList, AniList, Shikimori or MangaUpdates: status, chapters read and score per service, a badge on unsent changes. Filter by status, fresh changes first, tapping opens the title. The "Accounts" card shows signed-in services ("Manage" — Settings → Tracking), "Send" pushes queued changes, "Refresh from services" re-reads all entries (one failing service does not stop the others).
- **Downloads** (since 2.0.1) — the same queue as "Catalog → ⋮ → Downloads" (see [Downloads](#downloads)), and a link to the download settings.

## Text selection

Select a word or a fragment — a floating panel appears: copy, color, note, dictionary, translate, speak, web search, share and your buttons (URL templates with `{text}`/`{lang}` or "Send to app"). Button order and set — Settings → Text selection.

## Dictionary, translation and words

- **A word tap** (if enabled) opens a card: the dictionary entry (offline dictionaries → online), translation, pronunciation, "Save word" — together with the context sentence and a link to the place in the book.
- **Dictionaries**: Dictionary → books icon → Import: StarDict (`.ifo/.idx/.dict(.dz)` in a ZIP), DSL (`.dsl`/`.dsl.dz`), Wiktionary JSON/JSONL (kaikki.org), JMdict (XML). Dictionaries can be toggled and reordered.
- **Translation**: offline (ML Kit, language packs downloaded on demand: Settings → Translation → Language packs) or online — Google, DeepL (key), LibreTranslate (server address), LLM (an OpenAI-compatible URL, key, model, your prompt). Mode and engine are chosen in settings.
- **Book translation** — from the book card or editor: creates a translated copy or a bilingual version (in the background, with a notification). Since 2.0.0 you can translate only selected chapters: "Selected chapters" on the book card or "Selected chapters, draft here" in the editor.
- **My words** — a list with level and tag filters, CSV/Anki export, CSV import.
- **Repetition** — cards (word → translation, translation → word, cloze), SM-2 intervals, a daily goal and a reminder.

## Notes, bookmarks, quotes

All of a book's annotations — "Notes" in the reader menu or on the book card; the global list — from the library. Search, color filter, favorites, jumping to the place in the book, a quote card as an image. Export: Markdown (Obsidian), JSON, HTML, TXT, Readwise CSV; Readwise CSV import.

- **A note on a selection** — the "Note" button on the selection panel; **a note on a page** (handy for PDF and manga) — "⋮ → Page note". Notes are written in Markdown, with a preview.
- **Tags** — write `#tag` right in the note text: tags save automatically, and searching `#tag` finds all such notes and highlights.
- **Bookmarks** — the bookmark icon at the top of the reading screen (or a button on the selection panel); bookmarks show as marks above the progress bar and in the contents list, the name can be edited on the "Notes" screen.

## Catalog

- **Sources**: OPDS catalogs (Project Gutenberg, Standard Ebooks, Feedbooks, ManyBooks, your own — "⋮ → Add OPDS", including Calibre/Kavita/Komga with a login), Gutendex, Open Library/Internet Archive, a "Local folder" with manga and built-in extensions: MangaDex, MANGA Plus, Webtoons.com, GlobalComix, AComics.
- **Languages**: sources in the device language and English show by default; chips above the list enable other languages or "All languages". Global search searches the same languages.
- **The source list**: above it — sorting ("Recent", "Title", "Language"; pinned always first) and, once there are more than six sources, a "Find a source" field. A source that recently did not respond or responds slowly is marked "not responding" / "responding slowly".
- **Search and filters in a source** — the magnifier and the filter icon (with the active count). In the filter dialog groups are cards: short ones open right away, a collapsed one shows what is selected, "✕" clears the group. Options are chips: one tap includes (✓), a second excludes (⛔), a third clears; long groups (genres, themes) have a "Find in …" field. Sorting — chips, tapping a selected order flips it. "Apply" searches; above the results the active filters show — tapping a chip removes it and re-searches, "Reset all" returns defaults. Under the search field — the last 10 queries (not remembered in incognito), "Clear" erases them.
- **A title**: description, chapters, "Add to library" (the heart; if you have custom tabs — pick where to shelve it right away), read/bookmark marks, chapter downloads, online reading. OPDS books download straight into the library (links without duplicates, EPUB and FB2 first).
- **Chapter numbers** — on the left of a chapter row: the reading-order number (1 — the first chapter, the total count for the last; copies of one chapter from different groups share a number). With "newest first" sorting the largest number is on top. Above the list — "Read X of N" with a bar and "Downloaded N"; in the reader, under the title — "Chapter 12 of 368". A chapter has icons for the date, the group and the page you stopped on.
- **Chapter sorting and filters** — a button above the chapter list (also "Chapters: N of M"): "By chapter number", "As in source" or "By release date", an arrow flips the direction; "Unread only", "Downloaded only", "Bookmarked only", "One chapter version" (hides copies of the same chapter from other groups) and scanlation group selection. Stored per title; "For all titles" makes them global, "Reset filters" restores defaults. The reader, "Continue" and downloads follow the reading order — from the first chapter to the last, skipping copies from other groups.
- **Chapter selection** — long-press a chapter; on top — "Select unread", "Select range" (between marked), "Invert selection", then mark as read, download or delete downloads.
- **The catalog library** — the filter icon: sorting ("Updated", "Title", "Unread", "Last read", "Date added", "Chapter count") and filters ("With unread chapters", "With downloaded chapters", "Completed"). Long-press a title — including "Download unread chapters".
- **Updates** — new chapters of favorites (a scheduled check, Settings → Catalogs). **Recent** — the latest chapters read from online sources (the shared reading history of all books and chapters — the "History" tab at the bottom).
- **Global search** — across all enabled sources at once; from there — **migration** of a title to another source carrying the progress. On top you see how many sources answered and how many were found; the "With results" chip hides empty and failed sources, a failed source gets its own "Retry". Each source's results — best matches with the query first.
- A slow site does not "hang" the screen: requests have deadlines, and transient errors (timeout, connection drop, "too many requests", 5xx) retry by themselves.
- **Novels** (since 2.0.0) — built-in novel sources RanobeLib (Russian) and NovelBin (English): catalog, search, chapters; a chapter opens in the book reader with the dictionary, translation and highlights.
- **Tracking** (since 2.0.0) — Settings → Tracking: sign into Shikimori, AniList, MyAnimeList or MangaUpdates; a "Tracking" button on a title page finds the title in the service and binds it. Finished chapters go to the list by themselves; offline — when the network returns. All bound titles are in Profile → Tracking. Details and app keys — [TRACKING.md](TRACKING.md).
- **Extensions** (like Mihon) — "⋮ → Extensions". The "Repositories" tab → "Add repository": paste a Mihon/Tachiyomi extension repository address (`index.min.json`, `repo.json` or a GitHub page) — or tap "Add to Mihon/Tachiyomi" on the repository site and Yomu opens itself. The address can be pasted any way: with or without `https://`, a GitHub link or an "Add to Mihon" link — "Paste" validates the repository immediately. The "Available" tab — installing (a language filter, search), "Installed" — updates, "Update all", removal, source settings. Repository extensions are trusted by its signing key; an APK from a file (and extensions whose repository is not added) wait for a decision in a block on top: "Trust" per extension or "Trust all" with a list. If an extension does not start, tap it — the card explains and shows the error text with a "Copy" button for the authors. 18+ content is hidden until the "Show 18+ extensions" switch is on.
- If a site demands a check (Cloudflare) — a built-in browser opens, pass the check and come back.
- **Source not installed** — if a title's extension was removed, the header says so and a card with a "Migrate" button appears below: find the title in another source and carry the progress over. Downloaded chapters still open. **"Outdated source"** — the extension was built for another version; update it in "⋮ → Extensions" or pick another source.

## Downloads

- **Download chapters** — the download button on a title card: the next 1, 5, 10 or 25 chapters, "Specify a number…", "Unread chapters", "All chapters" — one version of each chapter (from the group you read; groups hidden by filters are skipped). There are also "Delete read chapters" and "Delete all downloads". Selected chapters download from selection mode, and from the catalog library — long-press a title → "Download unread chapters".
- **Automatically** (Settings → Downloads and storage): "Download new chapters" — new chapters of library titles after an update check (scheduled or manual); "Download while reading" — the next 2, 3, 5 or 10 chapters of a library title while you read; "Auto-retries on errors" — 0 to 5. Also "Wi-Fi only", the number of parallel downloads, packing chapters into CBZ, auto-deleting read chapters, used space and cache clearing.
- **Speed** — "Pages downloaded at once" (1–6, default 3) in "Downloads and storage": pages of one chapter download in parallel. If a site starts answering "too many requests", lower the number.
- **The queue** — "Catalog → ⋮ → Downloads" or "Profile → Downloads": chapters grouped by titles. A group has "To the top of the queue" and a menu (pause, resume, cancel all of the title's chapters), a task — "To the top of the queue" and "Cancel". Failed downloads are collected separately — with the reason ("No network connection", "The site requires a check…") and a "Retry all" button; the screen menu has "Retry failed downloads", "Clear completed", "Clear the queue".
- Transient errors retry themselves with a pause ("Retry 1 of 3: …"); without network downloads wait and resume when it is back. At most 2 chapters download from one site at a time, so the site does not throttle you. Progress and the result ("Downloads finished") show in the notification.
- **The download notification**: tapping opens the Downloads screen; "Pause" (while downloading), "Retry" (after errors) and "Continue" work without opening the app. If storage fills up, the queue pauses with the reason "Not enough space" and a "Downloads paused: out of space" notification — free some space and tap "Continue".

## Appearance

"Settings → Appearance" (a preview on top, changes apply immediately):

- **Theme** — system, light or dark (dark by default since 1.5.0); **"Pure black"** — a black background in the dark theme for AMOLED screens; **"Dynamic colors"** — colors from the wallpaper (Material You, Android 12+) instead of the app accent.
- **Accent color** — lavender (default), purple, indigo, blue, teal, green, orange, red, pink, "Classic" (the 1.0–1.4 palette) or **custom**: hue and saturation sliders. Buttons, selected tabs, the navigation bar and cards repaint under the accent.
- **App icon** (since 1.7.0) — "Classic" or one of six new ones: "Spark", "Feed", "Fox", "Hanko", "Gaze", "Manga". The icon changes when you exit the app; on Android 13+ in themed-icon mode it repaints to the wallpaper. Some launchers remove the shortcut on an icon change — add Yomu again from the app list then.
- **Interface** — labels in the navigation bar (without them only the selected section has one), the app language, haptic feedback, "Fewer animations".

## Network and traffic

"Settings → Network and traffic":

- **Wi-Fi only** — downloads, the chapter-update check and translation language packs.
- **Data saver** — on mobile data the reader preloads only the next page, and new chapters and "download ahead" chapters are not downloaded automatically. Wi-Fi works as usual.
- **Load covers on mobile data** — if off, only covers that were already loaded show on mobile data.
- **Ask before reading online on mobile data** — when opening an undownloaded chapter from a title page: "Read", "Download" (into the download queue) or "Cancel".
- **Traffic used** — how much the app downloaded and sent since the chosen date: total, mobile and Wi-Fi, which network is active. "Reset counter" starts counting anew. Built-in browser pages are not counted, so the number can be lower than Android's.

## Editor

Open a book card → "Edit". Changes happen in a draft, every step has undo/redo; the draft survives restarts. "Save" — replace the original or save a copy.

- **EPUB**: metadata and cover; chapters (order, add, remove, rename, split by headings/blocks, merge); the table of contents (from headings/chapters, manual); **"Edit text"** (since 2.0.0) — visual chapter editing with the book's styles: bold, italic, underline, headings, lists, quotes, alignment, links, the book's images, search; XHTML/CSS editing with highlighting and validation; find & replace (regular expressions, "whole word", across the book); text cleanup (empty paragraphs, spaces, dashes, quotes, hyphens) and style cleanup (fonts, colors); images (add, replace, remove); book validation with auto-fixes.
- **Manga**: a page grid, multi-select, reorder, rotate, delete, insert, cover, margin crop (auto/manual), color correction, dual-page splitting and merging, recompression, ComicInfo.xml.
- **Manga page translation** (since 2.0.0) — open a page → "Translate page (OCR)". "Recognize text" finds all the page's text, or circle a bubble with your finger ("Draw a frame"). Each block has the recognized text, a translation ("Translate again"), painting the original over (the bubble color, white, black, no paint) and the text color. The eye shows the result, the checkmark bakes the translation into the page — one undoable step. "Translate pages automatically" does the same for selected pages without review. The OCR language — Settings → Manga and PDF; the translation engine and language — Settings → Translation.

## Tracking local books

Since 2.0.4 open a local book or manga card and tap **Tracking**, then **Link** by the chosen service. Sign-in and, if needed, your own app keys are required — [TRACKING.md](TRACKING.md). Enter chapters, status and score manually: chapter numbers are not detected from the file's pages. Bindings go into a backup; in this build they travel through WebDAV and the shared folder without tokens and tracker progress.

## Backups and sync

- Settings → Backup and sync: create a backup (the database, settings, optionally book files) and restore it; scheduled auto-backups into a chosen folder keeping the last N. Backups from older versions (1.0.0–1.2.0) restore into 1.3.0 — that is how data moves if a new version is signed with a different key and the old one must be removed.
- In this build a restore does not overwrite differing existing files or records: on a conflict the operation stops. Save a separate backup of the current library first and review the conflict; do not delete data without checking. Restoring requires hard-link support in the app's internal storage. Files from the backup may remain as unused copies if an error happens after they are staged, but existing files are not replaced. Real-device verification is still needed.
- **Sync** (Settings → Sync, since 2.0.0) — a shared folder (Syncthing, Google Drive) or a WebDAV server (Nextcloud, ownCloud, Yandex Disk, Koofr, NAS: the folder address, an app name and password, "Check connection"). Progress, status and tabs of books, highlights, notes, bookmarks, words and — optionally — the online library (titles, tabs, read chapters) merge. "Sync deletions" propagates deletions of metadata records and, with file sync enabled, of books: a book deleted on one device is deleted on the others only if it did not change there; changed copies are kept with a conflict. If sync stops on a problem, open Settings → Sync → Sync conflicts: it lists what stopped the exchange with actions — "Keep my version" / "Take the other version" for changed books, "Migrate to a stable identity" for old image folders, "Publish my version" / "Accept the other version" for folders with changed pages. Nothing is deleted or overwritten without your choice; the list clears after a successful sync. The experimental annotation protection checks versions before deletions and changes. Sync only devices with the same new Yomu version: older versions do not know the adoption and deletion markers. When: on app open, on exit and in the background.
- **Sync through GitHub** — pick "GitHub repository" as the sync method, enter a personal access token (fine-grained: Contents read and write on the repository) and the repository as `owner/name`, or tap **Create a private repository** (the token then also needs permission to create repositories). Use the same repository on every device. Book files and image folders are synced too, as `books/yomu-book-<hash>.bin` (GitHub accepts up to 100 MB per file; a larger book is reported as a problem and stays local). The repository must stay private.
- **Shared-folder recovery:** writing any sync files needs a provider that supports rename. On failure a file like `yomu-sync.json.yomu-backup-…`, `yomu-books.json.yomu-backup-…`, `yomu-tracking.json.yomu-backup-…` or `yomu-folders.json.yomu-backup-…` may remain. Sync of that file stops until it is reviewed. Stop sync on all devices, keep copies of both the main file and the backup elsewhere; then check their contents and, if needed, manually restore the right file under the original name. Only then remove the backup copy from the shared folder and sync again. If it is unclear which version is correct, do not delete or overwrite the files. This is protection against an interrupted write, not a guarantee of cloud-provider atomicity: devices still need to sync one at a time.
- **Book files** (off by default): on each device pick a WebDAV server or shared folder in Settings → Backup and sync → Sync, enable **Sync book files** and tap **Sync now**. The server must support strong ETags and conditional writes; HTTPS is recommended. Files are uploaded without app-side encryption, so the provider can see them. Extra space and traffic are needed. The experimental shared-folder transfer requires provider rename support; sync devices strictly one at a time. Image folders transfer experimentally: new folders get a stable identity right away, previously imported ones migrate via "Migrate to a stable identity" on the conflicts screen (page order, positions and annotations are preserved; other devices follow on their own). Changing a folder's pages (replacing, deleting, adding images) does not stop the other books: the folder appears in conflicts — publish your version or accept the other one; positions on changed and removed pages reset with a report, annotations of such pages stay in place but the reader refuses stale jumps. A changed regular book file also lands in conflicts: "Keep my version" publishes it keeping progress, annotations and tracker bindings, "Take the other version" replaces the local file. If the file changed on both devices, the app will not choose for you. Close the reader before editing a folder's files; sync while that folder's reader is open is blocked. All devices of one target must run the same Yomu version. Restoring a backup resets the local merge bases (the first sync after it only adds). Server blobs are not deleted by deletions — space can be freed manually. These changes have not been verified on real devices, cloud folders and WebDAV.
- **Import from Mihon / Tachiyomi** (since 2.0.0) — Settings → Backup and sync → Import from Mihon / Tachiyomi, pick a `.tachibk` or `.proto.gz` backup: titles, chapters, read marks, bookmarks, history, categories (as tabs) and tracker bindings transfer. Titles of sources that are not installed are kept: install the extension and they open. Extension repositories from the backup are added with a button in the import result.

## Privacy

- Settings → Privacy and security: PIN/biometric lock (instantly or after a delay), hiding contents in recents (also blocks screenshots). Incognito mode for the catalog (no reading history) — Settings → Catalogs.

## If something does not work

- Settings → Advanced → Error log — saved crashes (the last 50); they can be sent to the developers. Enable "Verbose logging" for diagnostics.
- "Something went wrong. Details — in the error log" — one action failed, the app keeps working; the error report is in the log.
- "WebView unavailable" — the EPUB reader, site checks, the DOCX page layout and the editor work through Android System WebView. Install, enable or update it ("Open in store"), then tap "Retry".
- A book does not open: check that the file is not DRM-protected and is accessible. If the file was moved or deleted, the reader says so — the "Specify the file" button re-binds the book (progress and notes are kept). A catalog book can simply be downloaded again — it takes the old one's place.
- Translation/OCR do not work offline: download the language pack; on devices without Google Play Services offline translation and OCR are unavailable.
