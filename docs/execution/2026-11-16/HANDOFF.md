## 3. Обязательные правила (из раздела 1 плана)

1. Перед правкой прочитать указанный символ целиком, его вызывающих и ближайшие тесты. Путь искать по имени класса,
   а не по номеру строки.
2. Не создавать вторые системы: один wheel, одна очередь загрузок, один backup manager, один владелец состояния.
   Расширять существующее.
3. UI не вызывает SQL/HTTP. Чистая логика — в `domain`, без Compose `Offset`, Android Context, Room entity, bitmap.
4. Не ослаблять тесты ради зелёного отчёта: не удалять assertions, не добавлять безусловный skip, не поднимать
   timeout без разбора причины.
5. Не менять source IDs, namespace, applicationId, ключ подписи, формат существующего backup без миграции.
6. Не делать commit/push/release без поручения пользователя.
7. Для каждого пакета — запись в `docs/execution/2026-11-16/STATUS.md` по шаблону раздела 17: ID, HEAD, статус,
   изменённые файлы, **реальные** команды и результаты, что осталось, device/live.
8. Статус `ACCEPTED` ставить только после всех обязательных проверок пакета. Иначе `CODE_VERIFIED` или `BLOCKED`.

## 4. Особенности этой среды (сэкономит часы)

- **`rtk proxy` буферизует вывод** и не показывает прогресс — сборка выглядит зависшей на 30+ минут. Использовать
  `.\gradlew.bat <tasks> --console=plain` напрямую. Gradle 8.14.3, демон на Java 21 (из `org.gradle.java.home`).
- **`--rerun-tasks`** нужен, если в тестовом классе была ошибка компиляции: Gradle переиспользует старый XML-отчёт, и
  кажется, что тест «не изменился». Признак — старый `timestamp` в `app/build/test-results/`.
- **`ExtendedFloatingActionButton` скрывает подпись от semantics** (см. `core/ui/.../YomuFab.kt`). Искать кнопку надо
  через `hasContentDescription("Read")`, а не `hasText("Read")`.
- **`DownloadedBookTest.downloadedBookStaysReadable` флакует** при полном параллельном прогоне: падает по своему
  `withTimeout(120_000)` внутри Room-запроса, изолированно проходит. Не «исправлять» увеличением timeout.
- **Roborazzi `shot()` на этой Windows-машине не создаёт файлы** в `app/build/outputs/roborazzi`. Визуальная приёмка
  только на Linux CI; локально проверять assertions, не картинки.
- **JUnit:** `domain/`, `source-api/` — JUnit 5 (`org.junit.jupiter`), имена тестов в бэктиках.
  `data/`, `app/` — JUnit 4 (`org.junit.Test`); в `feature/catalog` есть и Jupiter.
- **Koin:** модули используют позиционные `get()`. Добавили параметр в ViewModel — обновите модуль, иначе тест
  `everyViewModelResolves` упадёт. Новые зависимости уже зарегистрированы: `AudioSubscriptionRepository`,
  `ImportReportStore`.
- **Строки:** добавлять в `values/strings.xml` **и** `values-ru/strings.xml`. Общие — `core/ui`, специфичные — в свой
  feature. Не импортировать `app.yomu.R` в features.
- **Доступные иконки:** расширенного набора (Tune, FilterAltOff, Sort) нет. Проверять по существующим импортам файла.
- **PowerShell и XML:** при вставке строк через `Replace` в двойных кавычках `$s` съедается. После правки проверять
  `%1$s` в `strings.xml`.
- **Room валидирует и лишние индексы:** индекс, созданный только миграцией, ломает открытие БД («Migration didn't
  properly handle»). Индексы объявлять в entity; миграция создаёт те же имена.
- **`File.renameTo` не перезаписывает файл на Windows.** Для замены использовать
  `java.nio.file.Files.move(..., REPLACE_EXISTING)` (minSdk 26).
