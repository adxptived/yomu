# Отчёт по плану удобства Yomu. Проход 21 ноября 2026

Срез: рабочее дерево поверх `2ce3078` (26 изменённых файлов предыдущего прохода + правки этого прохода). Цель — пройти маршрут «открыть книгу → настроить вид → найти место → вернуться» и убрать места, где управление мешало чтению. План: [YOMU_UX_IMPROVEMENT_PLAN_2026-11-21.md](YOMU_UX_IMPROVEMENT_PLAN_2026-11-21.md).

## Что закрыто кодом в этом проходе

### UX-01. Управление на странице

- В нижнюю панель добавлен постоянный вход **«Найти»**: из скрытого режима оглавление, поиск и «Вид» доступны за два действия, а не через верхнее меню.
- Три подписанные кнопки делят ширину строки и не обрезаются на 320 dp; подпись переносится только при крайне крупном системном шрифте.
- Android Back теперь закрывает верхний слой: строку совпадений, подсказку о продолжении, «Вернуться», затем управление, и только после этого выходит из книги. Листы и диалоги закрываются своими окнами раньше.
- Пока открыто выделение текста или меню слова, таймер автоскрытия управления не запускается.
- Для TalkBack в скрытом режиме добавлено действие **«Показать управление чтением»** — центральный тап перестал быть единственным входом.

### UX-02. «Вид» как настройка книги

- В быстрой панели видно область «Эта книга / Все книги» и переключатель «Эта книга»; включение области не стирает общие значения.
- В полных настройках появилось действие **«Применить как общие»**: текущий вид книги становится оформлением новых книг, сама книга сохраняет свою копию. «Сбросить настройки этой книги» и отмена остались отдельными действиями.
- Карточка образца в настройках показывает фрагмент **открытой страницы**, а не нейтральный текст; для пустого или защищённого документа остаётся обычный образец.

### UX-03. Поиск места, выделение и переходы

- После выбора результата поиска на странице остаётся компактная строка **«3 из 12»**: предыдущее, следующее совпадение, весь список и закрытие. Переход по результатам не создаёт отдельный «Вернуться» на каждое совпадение — возврат ведёт к месту до поиска.
- В «⋮ → Недавние переходы» появился список всех запомненных мест (новые сверху) с главой, страницей и процентом. Один тап возвращает к месту; текущее место при этом тоже попадает в историю.
- После подтверждённого продолжения книга один раз показывает короткую отметку **«Продолжаем со страницы N»**; она исчезает сама или по кнопке, новые книги и книги с нулевым прогрессом её не показывают.
- В оглавлении текущая глава помечена «Вы здесь», у глав с закладками стоит отметка, ведущая к списку закладок. Для книг с 12+ разделами добавлен поиск по названию главы.
- В сетке страниц PDF и локальной манги: открытие на текущей странице, отметки закладок поверх миниатюр и фильтр **«Только отмеченные»**.

### UX-04 и UX-06. Библиотека и аудио

- Карточка «Продолжить» показывает место, а не только процент: «Глава 12 · 34%», «Стр. 42 · 23%» или число непрочитанных глав; для книги строится по сохранённому локатору.
- Долгое нажатие на карточку «Продолжить» открывает сведения о книге, не запуская чтение.
- Мини-плеер уже содержал название, главу, Play/Pause и переход в полный плеер; таймер сна показывает остаток и «До конца главы». Эти пункты проверены по коду, менять их не потребовалось.

### UX-05. Поиск по настройкам

- Поиск настроек понимает бытовые слова: «где файлы», «шрифт», «поля PDF», «таймер сна» находят нужный раздел или параметр, а не только точное название.

### §8. Источники книг и аудиокниг

- **SRC01.** Экран добавления начинается с поля ссылки. Вставленный адрес проверяется без выбора типа; «Поделиться → Yomu» с ссылкой открывает этот же экран с уже запущенной проверкой. Выбор типа и вход в аккаунт остались ниже для тех, у кого ссылки нет.
- **SRC02.** Проверка сама определяет OPDS, RSS/Atom, аудио и обычную веб-страницу. Для страницы извлекаются только явно объявленные `<link>` на RSS/Atom/OPDS; произвольные ссылки не предлагаются. Поздний ответ на заменённый адрес отбрасывается. Прямой файл книги (EPUB/PDF/CBZ) из мастер пока не скачивается: для него остаётся импорт файла в библиотеке.
- **SRC03.** Успешное сохранение передаёт типизированный результат: ID каталога, ID книги аудио или подписки. Приложение сразу открывает каталог, плеер или созданную книгу, а не просто закрывает мастер. Повторное нажатие «Добавить» и повторная проверка защищены одним заданием.
- **SRC04.** Ошибка предлагает одно действие по причине: «Ввести логин», «Изменить адрес», «Повторить», «Открыть в браузере» или «Указать адрес каталога». Введённые несекретные поля сохраняются.
- Для страницы без фидов остаётся явное «Добавить как аудиоссылку» — так YouTube и подобные ссылки не теряют прежний сценарий.

## Аудит перед релизом 2.10.0

- Проверка источника больше не передаёт логин и пароль при перенаправлении на другой origin (схема, хост и порт). Добавлен тест с двумя серверами.
- `TimeFormatTest` сравнивает текст времени без учёта ширины пробела перед AM/PM: CLDR на JDK 21 и 25 использует узкий неразрывный пробел, из-за чего тест падал на локальной машине, хотя форматирование корректно.
- Для вертикального текста документ всей книги снова не собирается: он не используется этим режимом, а подготовка занимала время при открытии.
- `lintDebug` нашёл 69 пропущенных русских строк в аудио, каталоге, читалке, библиотеке и настройках — переводы добавлены; у виджет-кнопок аудио подавлено ложное `UseAppTint` (в RemoteViews нужен `android:tint`), а `linkedEditionId` теперь читается через `collectAsStateWithLifecycle`, а не через `StateFlow.value` в композиции.
- `detekt` падал на одном взвешенном `EmptyElseBlock` в обработчике TTS; обработчик переписан блоками, форматирующие замечания с нулевым весом не блокируют сборку.
- Полный набор debug-тестов, `lintDebug`, `detekt`, `assembleDebug` и `assembleFast` прогоняются перед тегом; результаты — в отчёте о релизе на GitHub.

## Что осталось и почему

Ни один пункт ниже не выдаётся за сделанный.

1. **Проверка на устройстве (UX-00, UX-07).** Нужен реальный ARM64-телефон и эмулятор: 320/360/411 dp, портрет и альбом, шрифт 1×/1,3×/2×, TalkBack, поворот, остановка процесса, установка поверх предыдущей версии. В этом проходе устройство не использовалось.
2. **SRC07, защищённое хранение паролей.** Пароли OPDS по-прежнему лежат в конфигурации источника; переход на защищённое хранилище с миграцией — отдельная задача с изменением зависимостей и формата базы.
3. **SRC05, SRC08.** Редактирование и повторная проверка уже добавленного источника, перенос каталога и живые серверы (OPDS/Audiobookshelf) требуют экрана «Мои источники» и реальных серверов.
4. **RF01, RF03–RF06, RF08–RF10, RF12–RF20.** Печатные страницы EPUB, пресеты по формату, сноски, метки PDF, двухколоночные сканы, отдельный разворот манги, офлайн-полка, серия, очередь и экспорт заметок остаются в плане; часть из них требует новых данных в парсере или движке, а не только UI.
5. **Визуальные снимки и Compose-проверки новых панелей.** Строка совпадений, история переходов и переключатель области ещё не закреплены скриншот-тестом; для этого нужен запуск Roborazzi с WebView-заглушкой.
